## 🚀 3 Pasos para Subir a GitHub

### Paso 1️⃣: Crea un repositorio (5 minutos)

1. Abre [GitHub.com](https://github.com/new)
2. Nombre: `julius-mayer-simulator`
3. Descripción: "Simulador interactivo sobre Julius Robert Mayer"
4. Selecciona **Public**
5. Haz clic en **Create repository**

### Paso 2️⃣: Clona el repositorio (2 minutos)

```bash
git clone https://github.com/TU-USUARIO/julius-mayer-simulator.git
cd julius-mayer-simulator
```

### Paso 3️⃣: Sube los archivos (3 minutos)

1. Copia TODOS los archivos descargados al carpeta
2. Ejecuta:

```bash
git add .
git commit -m "Initial commit: Julius Robert Mayer Simulator v1.0"
git push origin main
```

## 🔧 Personalización Rápida

### Cambiar colores
En `index.html`, busca:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

Reemplaza `#667eea` y `#764ba2` por tus colores.

### Cambiar título
En `<header>`:
```html
<h1>Mi Título</h1>
<p>Mi subtítulo</p>
```

### Cambiar imagen
En la sección Biografía, busca:
```html
<img src="https://upload.wikimedia.org/..." alt="Julius Robert Mayer">
```

## 🆘 Solucionar Problemas

### "La página no aparece después de crear el repo"
→ Espera 2-3 minutos y recarga (GitHub Pages puede tardar)

### "Error 404"
→ Verifica que el archivo se llama **index.html** exactamente

### "Página en blanco"
→ Presiona F12 para abrir consola y busca errores

### "Las imágenes no cargan"
→ Es normal, vienen de Wikipedia (conexión externa)
